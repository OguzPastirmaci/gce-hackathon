# GCE Hackathon

Combined working repo for the Slurm on OKE hackathon materials.

## Layout

- `slurm-operator/`: imported working tree from the Slurm Operator repo,
  including the OKE usage docs created during this work.
- `guides/`: imported working tree from the guides repo, including the
  `slurm-operator/multi-user-oke` end-to-end guide set.

The import is a working-tree snapshot, not a history-preserving subtree merge.
The original local repos are left untouched.
